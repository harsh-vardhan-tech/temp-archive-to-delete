# Prompts Log - Sprint 7 Registration Wizard

### Prompt 1
> React me ek multi-step registration wizard form banana hai jisme 3 steps ho:
> Step 1: Personal Info (First Name, Last Name, Date of Birth)
> Step 2: Account Details (Email, Password, Confirm Password)
> Step 3: Review & Submit
> Conditional rendering se views kaise toggle kare single route pe?

### Prompt 2
> Step 1 me data fill karke Next dabata hu aur Step 2 par jata hu, par jab Back dabata hu to Step 1 ka input data gayab ho jata hai. State lifting kaise kare parent component me taaki data persist rahe?

### Prompt 3
> Next aur Back button click karne par form refresh ho raha hai page reload ho jata hai. Is bug ko kaise fix kare?

### Prompt 4
> Email input me agar user ne '@' nahi likha hai to onChange par real time me red color ka error text kaise render kare?

### Prompt 5
> Password me minimum 8 characters check karna hai aur Confirm Password ko primary password se match karwana hai. Dono match na ho to dynamic error kaise show kare?

### Prompt 6
> Password input me eyeball icon lagana hai jisko click karne par password show aur hide ho (type="password" to type="text"). Kaise banaye?

### Prompt 7
> Next button ko tab tak disabled rakhna hai jab tak current step ke saare inputs valid na ho jayein. Conditional disabling logic kaise lagaye?

### Prompt 8
> Form ke top par dynamic progress bar chahiye jo "Step 1 of 3", "Step 2 of 3", "Step 3 of 3" aur visual progress percentage show kare.

### Prompt 9

### Prompt 10
> Step 3 par Review screen kaise banaye jisme user ka sara data dikhe aur Submit button click karne par console.log me final payload print ho aur ek Success UI screen aaye?

### Prompt 11
